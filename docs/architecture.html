与 Transformer 的差异

无注意力 LM

不用注意力语言模型，不做梯度续写；语言 = 构式槽位 + 概念检索 + 组合。

在线学习

学习 = 在线绑定 + 强化程序权重 + 巩固，不是反向传播。

功能代理

实现的是「可报告工作空间 + 预测 + 自我维护 + 目标 / 内言」的功能代理，不声称现象意识。
