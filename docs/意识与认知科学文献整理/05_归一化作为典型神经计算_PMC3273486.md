## 摘要

越来越多的证据表明，大脑依赖一组典型神经计算（canonical neural computations），在不同脑区和模态中重复应用类似操作来解决不同问题。归一化（normalization）是这种计算的一个有希望的候选者：神经元的反应被一个通常包括神经元池总和活动的公共因子相除。归一化最初被开发用来解释初级视觉皮层的反应，现在被认为在整个视觉系统以及许多其他感觉模态和脑区中运作。归一化可能是嗅觉表征、视觉注意的调节效应、价值编码和多感觉信息整合等操作的基础。它存在于从无脊椎动物到哺乳动物的多个物种的多种神经系统中，表明它作为一种典型神经计算发挥作用。

## 正文内容

### 引言

大脑具有模块化设计。大脑似乎以两种方式应用这一原则：模块化回路和模块化计算。解剖学证据表明存在跨脑区复制的典型微回路；生理学和行为学证据表明存在典型神经计算——在各种情境中应用相同基本操作的标准计算模块。

两种已确立的典型神经计算：
1. **幂运算**（exponentiation）：一种阈值化形式，在神经元和网络层面运作，维持感觉选择性、去相关信号、建立感知选择
2. **线性滤波**（linear filtering）：通过线性感受野加权求和，在视觉、听觉和体感系统的各个阶段执行

第三种计算——**除法归一化**（divisive normalization）——在各种神经系统中被观察到。归一化计算单个神经元反应与神经元池总和活动之间的比率。它在20世纪90年代初被提出以解释初级视觉皮层神经元的非线性特性。

### 无脊椎动物嗅觉系统中的归一化

果蝇（Drosophila melanogaster）通过受体神经元感知气味，每个受体神经元表达单一气味受体。受体神经元投射到触角叶（与脊椎动物嗅球类似的脑区）。

触角叶神经元的反应R随驱动它的受体神经元活动I增加：
```
R = γ·I^n / (σ^n + I^n)
```

掩蔽气味剂（不驱动该触角叶神经元）抑制对测试气味剂的反应。两种气味剂的交互被归一化方程准确描述：
```
R = γ·I^n / (σ^n + I_m^n + I^n)
```
其中I_m是其他受体神经元的池化反应。由于I_m作为分母中的加性项，增加它具有与增加σ相同的效果：在对数尺度上将反应曲线向右移动。

### 视网膜中的归一化

视网膜需要在广泛的光强度范围内运作（跨10个数量级）。视网膜使用解剖学解决方案（视杆和视锥光感受器、可调节瞳孔）应对部分范围，其余范围通过归一化进行光适应。

#### 光适应

光感受器反应随刺激强度增加。其敏感性（强度-反应曲线在强度轴上的位置）取决于背景光强度。增加背景强度在对数轴上将反应曲线向右移动，将曲线最陡峭部分（细胞对变化最敏感处）放在背景强度附近。

归一化使光感受器调整其工作点以折扣平均光强度。这近似于视觉对比度的神经度量。当背景光足够高时：
```
R - R_m ∝ C
```
其中C是局部对比度（局部光强度与平均值的相对偏差）。

#### 对比度归一化

光适应之后，视网膜信号被认为进入第二个归一化阶段，执行对比度归一化。该阶段根据周围空间区域的对比度调整对图像中一个位置的反应。

神经元j的反应R_j被常数σ加上整体对比度的度量相除：
```
R_j = γ·Σ_i w_i C_i / (σ + Σ_k α_k C_k²)
```

常见的探测方法是使用整体对比度和大小变化的光栅。增加光栅对比度在大窗口显示时导致反应饱和，但在小窗口显示时不会。

### 初级视觉皮层（V1）中的归一化

归一化模型最初是为了解释V1神经元的生理反应而开发的。V1神经元群体的反应由下式给出：
```
R(x,θ) = D(x,θ)^n / (σ^n + N(x,θ)^n)
```
其中x和θ表示每个神经元的偏好位置和朝向。分子包含刺激驱动D，分母中的归一化因子N由抑制场α(x,θ)决定。

#### 对比度饱和

V1神经元的反应随刺激对比度增加而饱和，与刺激朝向无关，因此与发放率无关。归一化解释了这一行为，因为刺激驱动和归一化因子都与光栅对比度c成比例。

#### 交叉朝向抑制

对测试光栅的反应被叠加在其上的掩蔽光栅（单独呈现时不引起反应，如朝向正交）抑制。归一化解释了这一效应，因为分母中的抑制随测试对比度和掩蔽对比度都增加，而分子中的刺激驱动仅随测试对比度增加。

#### 从驱动到抑制的转变

当掩蔽确实提供一些驱动时（如朝向接近偏好朝向），归一化做出重要预测：掩蔽单独呈现时应唤起活动，但在更有效刺激存在时应变为抑制性。

#### 环绕抑制

神经元对感受野内刺激的反应可被在周围区域放置额外刺激抑制。归一化解释了这一现象，因为抑制场覆盖比求和场更大的视觉空间区域。

#### 赢家通吃竞争

归一化正确预测V1群体在响应不同对比度刺激之和时表现出强烈的赢家通吃竞争。当低对比度垂直光栅被添加到高对比度水平光栅时，群体反应主要反映高对比度光栅。

### 其他皮层区域中的归一化

#### 视觉区域MT

MT（中颞区）神经元对视觉运动（速度和方向）选择性。已确立的MT反应模型涉及对V1群体活动运作的求和场，随后是归一化阶段。归一化有助于使速度选择性独立于空间模式。

#### 腹侧通路

在腹侧通路（物体识别通路）中，模型提出通过非线性池化操作整合特征。赢家通吃竞争可由归一化模型产生，特别是当指数较大时。当前最佳的计算机视觉目标识别系统遵循类似架构，归一化在其中增强目标识别准确性。

#### 初级听觉皮层（A1）

A1神经元对声音的反应取决于声音强度和背景。反应可被归一化方程定量表征：
1. A1反应随光谱时间听觉对比度增加
2. A1反应随听觉对比度饱和
3. 反应可被叠加单独呈现时不唤起反应的噪声刺激抑制

类似除法效应在猫头鹰的听觉中脑中也有表征。

#### 多感觉整合

灵长类动物的内侧颞上区（MST）神经元整合视觉和前庭线索以估计头部朝向。许多神经元的活动被两种模态调节，交互性质是除法的。归一化解释了为什么整合不同模态感觉输入的神经元根据每种模态的强度权衡各模态，为什么多感觉增强随刺激强度降低（"逆有效性原则"）。

#### 价值编码

猴子外侧顶内区（LIP）神经元编码扫视眼动的价值，但受相对而非绝对价值调节。归一化方程很好地拟合了对各种奖励值组合的反应。这表明归一化可能有助于解释理性选择理论的违反。

### 归一化与视觉注意

归一化模型已扩展以解释视觉皮层反应如何被注意调节。在扩展模型中，注意在归一化之前乘法性增强刺激驱动。

典型空间注意实验涉及两个空间分离的刺激，注意指向其中一个。视觉皮层记录显示响应注意刺激的神经元显示更强反应。

模型通过注意增益因子阵列A(x,θ)模拟注意效应。该阵列乘以刺激驱动，因此同时影响归一化方程的分子和分母。

该模型可解释文献中关于注意对视觉皮层神经元反应影响的表面矛盾：
- **对比度增益变化**：当刺激小且注意广泛时，注意增加对比度增益
- **反应增益变化**：当刺激大且注意窄聚焦时，注意增加反应增益

这些预测被系统操纵刺激大小和注意范围的行为研究进一步证实。

### 归一化的回路与机制

大量研究试图识别负责归一化的特定生物物理和细胞机制。大部分研究集中于GABA介导的抑制，但这种强调在果蝇嗅觉系统中被证明有用，在哺乳动物V1中则不那么有用。

#### 前馈与反馈回路

- **前馈安排**：归一化方程中对分母有贡献的信号本身未被归一化。已被提出用于家蝇视觉系统、果蝇嗅觉系统和哺乳动物视觉皮层的某些方面。
- **反馈回路**：传统上为初级视觉皮层提出，分母中的信号被认为起源于V1内的侧向反馈或来自高级视觉区域的反馈。

归一化信号的时间和感觉特性提供了线索：
- 来自神经元偏好位置附近的归一化信号（如交叉朝向抑制）类似于LGN反应（广泛选择性、缺乏适应性、极短延迟），提示前馈安排
- 来自更广泛视觉空间区域的归一化信号（如环绕抑制）类似于V1反应（朝向选择性、易受适应影响、更长延迟），提示反馈安排

#### 分流抑制

分流抑制增加膜电导而不引入去极化或超极化突触电流。电导增加直接从欧姆定律控制膜电位反应的增益：V = I/g。

分流抑制假说做出强烈预测：归一化不仅应影响反应幅度，还应影响其时间过程。增加电阻-电容电路（如细胞膜）的电导不仅降低增益，还降低反应的时间常数。这一预测在视网膜光适应和对比度归一化期间有效。

然而，V1中电导增加的证据混杂。细胞内测量显示电导确实随刺激对比度增长，但它并不像仅反映归一化强度那样与朝向无关。

#### 其他机制

- **突触抑制**（synaptic depression）：如果突触参与传递测试信号和掩蔽信号，其有效性以类似于归一化所需除法效应的方式降低
- **膜电位波动**：神经元的膜电位不仅取决于意在驱动神经元的传入信号，还取决于源自大脑其余部分的持续活动形式的其他信号。持续活动的幅度控制神经元的响应性。V1中刺激对比度增加时持续活动变弱，使神经元响应性降低，模拟除法抑制
- **平衡放大**：一些回路可能通过减少放大而非增加抑制来增加归一化

### 归一化的行为证据

心理物理学研究与神经生理学研究平行。归一化方程可用于对人类感知做出具体预测：

- **同时对比度-对比度错觉**：当中央纹理斑块被高对比度图案包围时，中央斑块的亮点显得更暗，暗点显得更亮。归一化模型通过以下方式解释：感知对比度是以神经元平均活动的单调函数，每个神经元被更大数量神经元（包括周围空间区域的）的池化活动抑制。
- **叠加和环绕抑制的心理物理学**：环绕抑制取决于目标和环绕的朝向和空间频率是否匹配，而叠加掩蔽的抑制在很大程度上是非特异性的。环绕抑制也略有延迟，而叠加掩蔽的抑制是即时的。

归一化相关计算的缺陷与以下疾病相关：弱视、癫痫、重度抑郁症和精神分裂症。这表明这些脑部疾病的根源可能不在于特定脑区或系统，而在于计算缺陷，归一化可能是这些疾病中受损的基本计算之一。

### 讨论

为什么归一化如此普遍？一个诱人的答案是将其视为非常常见的机制或网络的自然结果。然而，似乎存在许多支撑归一化的回路和机制，它们在不同物种和系统中不一定相同。因此，答案与计算有关，而非机制。

归一化被认为为神经系统执行的计算带来多种功能益处：
1. **最大化敏感性**：调整神经反应增益以有效利用可用动态范围
2. **对某些刺激维度的不变性**：如嗅觉识别不依赖浓度、视觉表征不依赖平均光水平或对比度
3. **解码分布式神经表征**：如MT中视觉运动的群体反应可解释为概率密度函数的离散样本
4. **刺激间辨别**：使不同刺激的神经表征更容易被线性分类器辨别
5. **最大池化（赢家通吃）**：当一个输入远大于其余输入时，神经元群体在近似相等时平均输入，在一个输入大得多时计算赢家通吃竞争
6. **冗余减少**：使V1对自然图像的反应在统计上更独立

作者提出归一化应被视为典型神经计算，加入已知的典型神经计算短名单：线性滤波、幂运算、循环放大、联想学习规则、巧合检测、群体向量和动力系统中的受约束轨迹。

## 关键结论

1. 除法归一化是一种广泛存在于不同感觉系统的计算，也可能在认知系统（如价值编码）中发挥作用。
2. 归一化计算单个神经元反应与神经元池总和活动之间的比率。
3. 归一化最初为解释V1反应而开发，现已在视网膜、LGN、MT、腹侧通路、听觉皮层、嗅觉系统、多感觉整合和价值编码中发现。
4. 归一化解释了多种神经现象：对比度饱和、交叉朝向抑制、环绕抑制、赢家通吃竞争、注意调节。
5. 多种回路和机制可执行归一化：前馈抑制、反馈抑制、分流抑制、突触抑制、膜电位波动、平衡放大。
6. 归一化的功能益处包括：最大化敏感性、维度不变性、促进分布式编码解码、增强刺激辨别、最大池化、冗余减少。
7. 归一化缺陷与弱视、癫痫、抑郁症和精神分裂症等脑部疾病相关。
8. 归一化应被视为典型神经计算，与线性滤波和幂运算并列。

## 归一化方程（Box 1）

基本归一化方程：
```
R_i = γ·D_j^n / (σ^n + Σ_k D_k^n)
```
- 分子：神经元的驱动输入D_j
- 分母：常数σ加上归一化因子（大量输入D_k的总和，即归一化池）
- γ：整体响应性
- σ：防止除零并决定响应如何随驱动输入增加而饱和
- n：放大单个输入的指数

扩展形式（包含求和场、抑制场、基线反应、时间平均）：
```
R_j = [γ·(Σ_k w_jk I_k)^n + β] / [σ^n + (Σ_k α_jk I_k^m)^p]
```
