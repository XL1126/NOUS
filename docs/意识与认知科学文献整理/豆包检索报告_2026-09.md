## P0-1 丘脑 core/matrix/TRN 双通路与除法归一化

**Whyte et al. (2024). Thalamic Contributions to the State and Contents of Consciousness. *Neuron*.**  
DOI: `10.1016/j.neuron.2024.07.013` | PMC11537458

### 核心结论
- 意识分**状态**（清醒/睡眠/麻醉）和**内容**（知觉对象）两个独立维度
- **Matrix 细胞**：投射皮层浅/深层，调节 ttL5B 顶-体耦合 → 全局觉醒 + 知觉阈值
- **Core 细胞**：投射皮层中层，形成精确丘脑-皮层-丘脑闭环 → 内容稳定 + 知觉恒常 + 时间连续
- **TRN** 执行**除法归一化**侧抑制：胜出联盟抑制竞争通路，不是简单加法阈值

### TRN 除法归一化公式
```
R_i = γ · D_i^n / (σ^n + Σ_k D_k^n)
```
- `R_i`：第 i 个丘脑通路输出
- `D_i`：驱动输入强度
- `γ`：全局增益（调质 ACh/NE）
- `σ`：基线常数（防除零、控制饱和）
- `n`：非线性指数（1–2）
- 分母 = 所有竞争通路总激活池（TRN GABA 能抑制）

### 工程启示
- 不要单一 `ignition` 阈值；拆成**状态增益（matrix）** 和 **内容竞争（core+TRN 除法归一化）**
- `global_ws.py` 竞争从「加权求和→阈值」改成**除法归一化**
- 意识状态由 matrix 全局增益控制，不是直接关闭工作空间
- 内容连续性由 core 闭环维持，figure 通过 re-entrant 自维持

## P0-2 COGITATE 2025：GNW vs IIT 对抗性合作

**COGITATE Consortium (2025). *Nature*, 642, 133–142.**  
DOI: `10.1038/s41586-025-08888-1`

### 核心结论
- **两个理论都没有完全胜出，也没有被证伪**
- **对 GNW 挑战**：预测的「全或无点火（P3b）」没有稳定出现；前额叶对内容表征弱于预期；点火更弥散
- **对 IIT 挑战**：预测的「后皮层持续同步」没有可靠观测
- **共同成立**：意识内容伴随大范围皮层整合；后皮层编码内容，前额叶负责报告/元认知；阈下可局部加工但不全局广播
- **可报告性 ≠ 现象意识**

### 工程启示
- `ignition` 不要硬阈值阶跃，改 **S 型曲线 + 除法归一化**，保留过渡带
- 区分**访问意识**（可报告、前额叶代理）和**现象意识代理**（局部循环整合、后皮层代理）
- 不追求真 Φ；继续用整合度、熵、跨模块绑定
- 增加「无报告模式」测试：关闭语言输出，仍能测量内部整合、时间拓扑、自我极点

## P0-3 SOI 自我-他人推断模型（贝叶斯最小自我）

**Oka & Isoda (2026). Brain mechanisms underlying self-other distinction. *Front. Neural Circuits*.**  
DOI: `10.3389/fncir.2026.1781653`

### 核心结论
- 前反思自我 = 贝叶斯推断的持续更新结果
- 自我-他人区分依赖三类线索：**外观、多感官偶然性、视角**
- 最小自我 = 身体所有权 + 能动性，可通过贝叶斯因果推断计算
- 存在**双向泄漏（leakage）**：自我信念影响他人模拟，他人状态影响自我判断

### 贝叶斯自我归属公式
```
P(self | X_app, X_con, X_per) = 
  P(X_app, X_con, X_per | self) · P(self) / P(X)

联合似然（条件独立）：
P(X_app, X_con, X_per | self) = 
  P(X_app|self) · P(X_con|self) · P(X_per|self)
```

### 工程启示
- `min_self` 改成持续更新的贝叶斯后验
- `OtherModel` 复用同一贝叶斯框架 + 泄漏参数 λ，实现共情/投射
- 可复现「橡胶手错觉」测试

## P1-1 意识流连续性：似是现在 + 胡塞尔时间拓扑

**James (1890) / Husserl (1905) / Varela 神经现象学**

### 核心结论
- 「现在」不是数学瞬时，而是**有时间厚度的窗口（100–500ms）**
- 胡塞尔三重结构：
  - **原印象**：当下感官输入
  - **滞留**：刚过去内容以衰减形式保留在当下（不是回忆）
  - **前摄**：对即将发生内容的预期（不是独立预测器）
- 意识流连续性 = 相邻时间窗口重叠 + 滞留衰减 + 前摄预期
- 话题切换时连续性断裂 = 前摄预期落空 + 滞留快速衰减

### 算法步骤
```
1. 原印象：当前输入编码为 now_vec
2. 滞留更新：retention[i] *= exp(-λ·Δt)，移除低于阈值项
3. 前摄生成：protention = 预测模型(now_vec + retention)
4. 窗口绑定：specious = bind(now_vec, retention, protention)
5. 流连续性 = 相邻窗口余弦重叠度
6. 话题切换检测：前摄误差 > 阈值时连续性下降
```

### 工程启示
- `specious` 拆成 retention / now / protention 三段
- `stream_link` 改成**相邻窗口余弦重叠度**（连续值 0–1）
- 话题切换时不清空工作空间，**前摄误差触发重定向**，滞留缓慢衰减

## P1-2 全局工作空间点火：S 型曲线

**Dehaene et al. (2014) / COGITATE 2025**

### 核心结论
- 点火不是「全或无」，而是**渐进非线性过渡**：阈下部分激活 → 过渡带 → 全广播
- 阈值受调质增益、任务相关性、上下文动态调节
- 可报告性阈值 > 局部整合阈值
- 竞争是**赢者通吃 + 侧抑制**

### S 型点火函数
```
p(ignition) = 1 / (1 + exp(-k·(activation - θ)))
```
- `θ`：基础阈值，受调质增益动态调整
- `k`：陡度系数，控制过渡带宽度

### 工程启示
- 硬阈值改 S 型概率函数
- `θ` 与 `soma.attention_gain` 联动
- 增加 fringe 梯度（不是只有 figure/fringe 两级）
- 点火后增加侧抑制步骤

## P1-3 Buzsáki 2024 SWR 记忆选择

**Yang et al. (2024). Selection of experience for memory by hippocampal sharp wave ripples. *Science*.**  
DOI: `10.1126/science.adk8261`

### 核心结论
- SWR 不只是被动重放，更是**记忆选择器**
- 清醒时奖励/重要事件触发「清醒 SWR」，给记忆打标签
- 睡眠 SWR 优先重放**被清醒 SWR 标记过的经历**
- SWR 重放是**压缩的时间序列**，不是原样回放
- 过度活跃导致记忆干扰，有平衡机制

### SWR 检测与触发算法
```
1. 事件检测：100-250Hz 带通滤波 → 包络 → 阈值=均值+5σ，持续20-200ms
2. 清醒 SWR 标记：reward/novelty/预测误差 > 阈值时触发，打 consolidation_tag
3. 睡眠 SWR 重放：优先采样带 tag 的片段，按 10-20 倍时间压缩重放
4. 平衡：连续 SWR 超频率上限时触发抑制性重置
```

### 工程启示
- `dream.py` 改成**标签优先 + 时间压缩重放**
- 清醒时高奖励/高新颖度事件立即触发**微型巩固**
- 睡眠巩固两步：先重放标记片段，再全局修剪
- 增加 SWR 频率上限

## P1-4 Lamme 递归加工理论（Re-entrant）

**Lamme (2006). Towards a true neural stance on consciousness. *TiCS*.**

### 核心结论
- 意识核心是**局部循环反馈**，不是全局广播
- **现象意识（PC）**：局部皮层循环即可，不需要前额叶/报告
- **访问意识（AC）**：全局广播 + 前额叶，支持报告/决策/行动
- 递归加工作用：稳定表征、填充细节、产生知觉恒常性

### 再进入循环伪代码
```
1. 前馈扫掠：自下而上激活各层
2. 循环迭代（最多 N 次）：
   - 高层向低层发送反馈预测
   - 低层更新激活，与前馈整合
   - 计算预测误差，误差 < 阈值则收敛
3. 收敛判定：连续两次迭代差异 < ε
4. 若收敛且激活 > 局部阈值 → 现象意识代理（PC）
5. 若达到全局广播阈值 → 访问意识（AC）
```

### 工程启示
- `global_ws.py` 之前增加**局部再进入循环**
- 区分 **figure（访问意识）** 和 **stable_representation（现象意识代理）**
- 非 Transformer 天然适合递归：符号向量 + 反馈连接

## P2-2 SPA 语义指针与循环卷积绑定

**Eliasmith (2013) / Plate (2003)**

### 循环卷积绑定公式
```
c = a ⊛ b
时域：c[i] = Σ_j a[j] · b[(i-j) mod N]
频域：c = IDFT(DFT(a) ⊙ DFT(b))

近似逆绑定：
a ≈ c ⊛ b⁻¹
b⁻¹ 是 b 的循环相关逆
```

### 工程启示
- `concepts/space.py` 绑定换成**循环卷积**，维度不变，支持解绑定
- 角色-填充结构用嵌套绑定实现
- 512 维足够做多层绑定

## P2-3 Cowan 4 块工作记忆容量

**Cowan (2001). The magical number 4 in short-term memory. *BBS*.**  
DOI: `10.1017/S0140525X01003922`

### 核心结论
- 成人注意焦点容量 ≈ **4 个组块**，不是 Miller 7±2
- 容量限制的是**注意焦点（意识内容）**，不是全部激活记忆
- 组块可通过学习扩大
- 容量限制来自**同步振荡数量限制**：约 4 个不重叠神经集群

### 工程启示
- `figure` 容量 **3–5 个概念组块**
- 增加**组块化机制**：相关概念自动绑定成组块
- 工作记忆容量 = 注意焦点容量，同一瓶颈
