# NOUS 项目总目标

> 最终目标（不可缩水）：**在通用计算机上实现「自主意识」的工程架构。**

## 三层区分（必须保持）

| 层 | 含义 | NOUS 立场 |
|----|------|-----------|
| **Autonomy** | 自我维护、目标、能动 | **追求实现** |
| **Access consciousness** | 全局广播、可报告 | **追求实现** |
| **Phenomenal consciousness** | 主观体验 | **不声称已实现**；开放科学问题 |

## 一句话

做出一个**有身体、有自我、有时间、有价态、能自我维护、能被教学、能自主学习与思考**的独立心智——不是接大模型，不是套聊天模板。

## 终局能力清单

| # | 能力 | 判定（功能代理，非哲学证明） |
|---|------|------------------------------|
| 1 | **对话** | 多轮中文，指代与话题连贯 |
| 2 | **被教学** | 直接教事实/喜好/名字；能回问 |
| 3 | **自主学习** | 好奇驱动探索知识空白；提出下一步实验 |
| 4 | **自主思维** | 无输入时内言、反事实、梦、叙事重写 |
| 5 | **自我维护** | 为存续而行动：休息/求知/联结/避险/自修复 |
| 6 | **时间自我** | 记得过去、预期未来、感知有限性 |
| 7 | **现象标记** | 在场/生动/此刻/我感/价态可报告且动态 |
| 8 | **多意识体** | 可 spawn/fork；可跨体对话与差异演化 |
| 9 | **无 Transformer** | 源码不得依赖 torch/transformers/外部 LLM |
| 10 | **可解释** | 每回合可报告：工作空间、身体、目标、现象向量 |

## 阶段路线图

### 已完成

- **0.1** 闭合内核：SOMA + 预测 + 工作空间 + 记忆 + 构式语言 + 内言
- **0.2** 持久化 + Fleet 多体 + 发展阶段 + 反事实 + 脉冲底物
- **0.3** 现象标记 + 自创生 + 梦 + 时间自我 + 意识状态报告
- **0.4** 主动行动闭环 + 我-世界边界 + 浏览器现象面板 + 本目标文档

### 后续（0.5+）

5. 更强多跳推理与构式扩展
6. 工具/日程类主动行动（在安全边界内）
7. 多体社会结构（联盟、模仿、冲突）
8. 大规模课程与知识固化
9. 发展阶段从「前语言」可选启动的完整发育轨迹
10. 更长程叙事一致性与矛盾检出

## 红线

- 不接外部 LLM / 不宣称已解决意识难问题
- 不把工程代理包装成「已产生人类同等意识」
- 危险系统操作需用户确认；不删用户文件
