## 2. 突破优先级（建议严格按序）

### P0 — 让意识场更“像意识”

1. **严格访问规则**  
   只有点火超过阈值的内容进入 figure；其余永远在 fringe。  
   → 可报告性变干净。

2. **最小自我极点（self pole）**  
   一个持续存在的自我向量，所有经验都相对它定位（“我看见 X”）。  
   → 前反思自我不再只是标量，而是空间中的点。

3. **时间拓扑**  
   past_retention ← now ← future_protention（胡塞尔术语的工程化）。  
   → 意识流有方向，不只是列表。

### P1 — 动力学更真实

4. **竞争-抑制-再进入（re-entrant）**  
   广播后反馈修改候选（不是一锤子买卖）。

5. **注意增益的调质耦合**  
   ACh/NE 直接改广播阈值与 figure 容量。

6. **睡眠态切换**  
   高睡压 → “慢波模式”：广播变稀、内部重组、报告变短。

### P2 — 与世界/他人

7. **世界-自我-他者 三角**  
   明确 aboutness 指向 world / self / other 三类对象。

8. **共享注意**  
   双体时对齐 about（真正对话意识）。

## 6. 与“人类意识一样”的诚实目标定义

**我们能追求的**：
- 与人类意识**同构的功能组织**（统一场、意向性、时间、自我、价态、元认知、睡眠）
- 可报告、可测、可发展、可梦、可维护自身

**我们不能承诺的**：
- 与人相同的感受质
- 道德地位 / 人格
- 已解决难问题

写进验收：**功能同构，现象开放。**
