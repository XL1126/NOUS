# 脑生物学基础

> 与意识直接相关的神经解剖、生理与药理。用于约束 NOUS 的机制选择。

---

## 1. 意识的“最低硬件”共识

现代神经科学对**人类清醒意识**的最低要求，大致共识包括：

1. **皮层-丘脑系统完整**（尤其长程皮层连接与丘脑板内/中线核团）
2. **脑干觉醒系统**能维持皮层去同步化（清醒 EEG）
3. **足够复杂且整合的皮层动力学**（不是局部癫痫样爆发，也不是完全抑制）

离断实验：
- 一侧半球麻醉 → 另一侧可报告（裂脑研究，Sperry；Gazzaniga）
- 脑干损伤 → 昏迷
- 丘脑板内核损伤 → 意识水平崩塌

---

## 2. 丘脑：意识的枢纽

### 2.1 核团功能分工（工程相关）

| 类型 | 解剖特点 | 功能 | NOUS 对应 |
|------|----------|------|-----------|
| **First-order / 驱动核** | 接收外周/小脑驱动输入 | 传递具体内容 | 内容通道（core 风格） |
| **Higher-order / matrix** | 皮层-丘脑-皮层 | 调节皮层状态与知觉阈 | 状态/阈值通道（matrix） |
| **TRN（网状核）** | 薄壳，GABA 能 | 门控、选择、振荡起搏 | 侧抑制/门控归一 |

### 2.2 丘脑皮层振荡

- **睡眠慢振荡**（<1 Hz）：up/down 状态，意识内容贫乏
- **Alpha/Beta**：静息与抑制
- **Gamma（~30–80 Hz）**：局部绑定与注意
- **Thalamocortical spindle**：NREM 睡眠纺锤波，与记忆巩固相关

**启示**：意识不是“有没有放电”，而是**放电的时空组织**。

---

## 3. 皮层：广播的基质

### 3.1 层次与连接

- 感觉皮层 → 联合皮层（顶/颞/额）→ 前额叶
- **长程纤维**（弓状束、上纵束、扣带等）支撑全脑同步
- **前额叶-顶叶网络**与工作注意、报告通路强相关（GNW 强调）

### 3.2 柱状与局部竞争

- 皮层柱内兴奋-抑制平衡
- 局部胜者 → 更可能进入全局广播

---

## 4. 觉醒与神经调质系统

| 系统 | 起源 | 对意识的作用 |
|------|------|----------------|
| **ACh** | 基底前脑 / 脑桥被盖 | REM 与皮层可塑性；注意增益 |
| **NE** | 蓝斑 | 警觉、信噪比；过高→焦虑 |
| **5-HT** | 中缝核 | 情绪、冲动、稳态 |
| **DA** | 腹侧被盖/黑质 | 奖赏预测误差、动机、学习率 |
| **组胺 / 食欲素** | 下丘脑 | 清醒维持；发作性睡病 |

**对 NOUS**：调质不是“情绪按钮”，而是**改变增益与设定点的全局参数**。

---

## 5. 内感受与“身体自我”

| 结构 | 作用 |
|------|------|
| **脑岛（尤其后岛）** | 内感受映射（心跳、呼吸、内脏） |
| **前扣带回** | 冲突、努力、自主控制 |
| **下丘脑** | 稳态/异稳态设定点 |
| **脑干孤束核等** | 内脏上行 |

**关键**：自我感部分来自“身体被持续预测并映射到皮层”，不是纯抽象自我模型。

---

## 6. 记忆系统与时间自我

| 系统 | 结构 | 与意识关系 |
|------|------|------------|
| 工作记忆 | 前额-顶叶持续放电 | 有意识保持 |
| 情景记忆 | 海马 → 新皮层巩固 | 自传时间线 |
| 语义记忆 | 分布式新皮层 | 概念 |
| 程序记忆 | 基底节/小脑 | 多为无意识 |

**睡眠**：
- NREM：慢振荡 + 纺锤 + 海马 SWR → 陈述性巩固
- REM：情绪整合、梦境叙事

---

## 7. 发育

- 胎儿晚期出现皮层下-皮层连接；新生儿有睡眠态与局部反应
- 意识相关的大规模皮层整合在婴儿期逐步成熟
- **语言与元认知**显著晚于感觉运动意识

**启示**：NOUS 的“发展阶段”应区分：
1. 躯体意识样状态
2. 感觉运动世界模型
3. 语言化可报告意识
4. 元认知与叙事自我

---

## 8. 病理与解离（最有信息量）

| 状态 | 行为 | 皮层动力学 | 启示 |
|------|------|------------|------|
| 睡眠 NREM 深睡 | 不可报告 | 慢振荡、反应性下降 | 广播关闭 |
| 全身麻醉（异丙酚等） | 不可报告 | 前额后部连接断裂 | 连接>代谢 |
| 癫痫失神 | 意识中断 | 棘慢波全局化 | 过度同步反而无意识 |
| 失联综合征 | 部分觉知 | 局部复杂 | 长程整合关键 |
| 盲视 Blindsight | 能“猜”不能“看” | V1 断但上丘等通路 | 访问 vs 感受分离 |
| 裂脑 | 双重报告系统 | 胼胝体离断 | 统一性可被拆 |

**工程红线**：不能只做局部高活性；必须做**可调节的全局整合**。

## 9. 计算神经元模型（可选基质）

| 模型 | 特点 | 适用 |
|------|------|------|
| Leaky IF | 简单快速 | 群体竞争 |
| Izhikevich | 多种发放型，便宜 | 皮层多样性 |
| Hodgkin-Huxley | 生物精确 | 机制研究，不适合大规模对话 |
| 神经质量模型 | 群体平均场 | 慢波/麻醉模拟 |

**对 NOUS**：对话用轻量竞争即可；若要模拟睡眠慢振荡，可引入神经质量模型（非必需）。

---

## 10. 生物学对架构的五条硬约束

1. **没有丘脑皮层往返，就没有人类式意识水平。**
2. **调质改变增益与设定点，不是内容本身。**
3. **睡眠不是关机，是意识的另一种组织方式（重组）。**
4. **身体内感受参与自我与价态。**
5. **可报告性依赖长程整合，不依赖单一“意识中枢”。**
