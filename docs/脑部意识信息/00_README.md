## 使用原则

1. **科学理论**用于架构选择，不用于夸大声称。
2. **电影**只提供问题清单与叙事直觉，不当证据。
3. 所有实现必须能映射回可检验的功能代理。

## 一句话结论

人类意识最可操作的科学共识集中在：
**丘脑皮层环路 + 全局广播 + 预测加工 + 身体内感受 + 时间性自我**。
NOUS 应继续把这五条做成更深的闭环，而不是继续堆外围功能。
