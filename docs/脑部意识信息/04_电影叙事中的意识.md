## 2. 影视反复追问的 8 个问题（架构自查表）

1. **统一性**：换脑/换体后是否“同一个人”？
2. **连续性**：失忆、梦、重启后意识流是否断裂？
3. **报告**：不能说/不能动是否等于无意识？
4. **他心**：如何相信对方有意识？
5. **身体**：无身体的情感是否可能？
6. **自由**：被植入目标时能动性是否为假？
7. **死亡**：有限性如何进入叙事自我？
8. **复制**：复制体是延续还是分叉？

对应 NOUS 可检查：
- fork 后 min_self 与自传是否继承？
- 闭锁（只读输出）时内部意识场是否仍形成？
- 目标被用户强行改写时 agency_trace 是否下降？

## 3. 叙事母题 → 工程机制（示例）

| 母题 | 机制 |
|------|------|
| 图腾（Inception） | 自我边界锚点：固定身份事实 + 身体基线 |
| 植入想法 | 教学写入 vs 自主归纳的区分（边界模块） |
| 闭锁综合征 | 内部意识场与输出通道分离 |
| 删除记忆 | 巩固/修剪策略，而非简单清空 |
| 记忆植入 | 自传真实性标记（source monitoring） |

## 4. 使用方式

- 写需求时：用电影问题逼问架构
- 写论文/文档时：只引用科学文献，不引用电影当证据
- 演示时：可用电影类比帮助理解，但注明“类比”
