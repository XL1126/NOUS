Independent Mind Architecture · v1.5.0

在通用计算机上，构建一个可运行的意识相关功能架构

NOUS（希腊语 νοῦς，心智 / 理智 / 意识）不是一个套壳聊天机器人，而是一套完整的工程路线： 身体稳态驱动、全局工作空间广播、NERI 非平衡动力学、时间自我与记忆巩固—— 全部模块在同一闭合循环中互相驱动，不依赖外部 Transformer / LLM。

查看源码 阅读意识立场 项目文档库
诚实边界： 系统实现了意识科学中大量可操作的功能要件（统一意识场、意向性、时间拓扑、前反思自我、 连续意识流、睡眠–觉醒状态机、自创生、梦、NERI 动力学签名等）。 但主观体验（qualia）无法判断——科学上没有仪器能测「这个系统有没有主观体验」。 NERI 签名是必要条件的工程代理，不是充分条件。通过签名 ≠ 有意识。 本项目在开发机上已做到工程极限，仅做参考。

三层意识区分（项目必须保持）

Autonomy

自主性

自我维护、目标、能动。SOMA 稳态 + 策略选择 + 生存驱动。追求实现。

Access consciousness

访问意识

全局广播、内容可报告、可被其他子系统调用。追求实现。

Phenomenal consciousness

现象意识

主观体验本身。不声称已实现；这是开放的科学 / 哲学问题，不是验收标准。

一句话目标

做出一个有身体、有自我、有时间、有价态、能自我维护、能被教学、能自主学习与思考的独立心智—— 不是接大模型，不是套聊天模板。源码不得依赖 torch / transformers / 外部 LLM。

核心子系统

src/soma/body.py

SOMA 身体驱动

能量 / 睡眠 / 压力 / 社会 / 好奇；异稳态设定点漂移、构造情绪、注意力与学习增益。

src/workspace/

全局工作空间

候选竞争 → 点火阈值 → 广播；可报告内容 = 广播集。TRN 除法归一化门控。

src/predictive/

预测模型

层级生成模型预测下一状态；惊讶 / 新颖度驱动注意、学习率与好奇探索。

src/consciousness/neri.py

NERI 整合器

Langevin SDE 非平衡递归整合；双稳势吸引子 ≈ 原型概念，状态空间可涌现思维内容。

src/memory/systems.py

五类记忆

工作 / 情景 / 语义 / 程序 / 自传；睡眠压缩、叙事重写、弱联结修剪。

src/language/

构式语言 v2

构式槽位 + 概念检索 + 组合生成；受情绪 / 能量 / NERI 偏置影响，非预训练续写。

src/self_model/

目标 / 内言 / 自我

目标栈、元认知、自我提问、反事实、他者模型、默认模式网络式自发思维。

src/fleet.py

多体 Fleet

spawn / fork 独立意识体实例；跨体状态可见、可差异演化。
