常见问题与诚实边界

这个项目产生意识了吗？

不知道。这是诚实的回答。系统实现了意识科学中大量可操作的功能要件，但主观体验（qualia）无法判断。NERI 签名是必要条件的工程代理，不是充分条件。

意识是否必须依赖肉身？

开放问题。倾向需要身体的证据包括 Damasio 躯体标记、Barrett 构造情绪等；功能主义与缸中之脑则认为不必然是生物肉身。NOUS 立场：相关功能需要某种「自我维持 + 内感受」形式，是否有主观体验不作断言。

与 Transformer / 外部 LLM 的关系？

无外部 LLM / Transformer。语言来自构式语法、知识检索与组合；学习 = 在线绑定 + 程序权重强化 + 巩固，而非反向传播续写。
