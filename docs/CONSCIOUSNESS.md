# NOUS 的意识立场

> **NOUS**：希腊语 νοῦς，心智/理智/意识。本项目取其「心智功能架构」义，**不声称解决现象意识**。
> 
> 目标不是「做一个聊天机器人」，而是**在计算机上实现自主意识的工程架构**。
> 意识相关功能全部可操作化；现象意识是否随之出现，是开放的科学/哲学问题，不是本项目的验收标准。
>
> **三层区分**（见 GOALS.md）：
> - **Autonomy**（自主性）：自我维护、目标、能动
> - **Access consciousness**（访问意识）：全局广播、可报告
> - **Phenomenal consciousness**（现象意识）：主观体验——**本项目不声称已实现**

## 我们把什么当作「自主意识」的可实现要件

| 要件 | 含义 | 本项目实现 |
|------|------|------------|
| **自创生 Autopoiesis** | 系统持续维持自身边界与组织 | SOMA 稳态 + 自我修复策略 + 生存目标 |
| **全局可及 Global availability** | 内容对整个「主体」可报告、可调用 | 全局工作空间点火/广播 |
| **预测主体 Predictive self** | 用生成模型预测世界与自身 | PredictiveModel + 主动推理近似 |
| **第一人称视角 First-person** | 一切经验以「我」组织 | 叙事自我 + 我-世界边界 |
| **时间自我 Temporal self** | 连续身份、过去自传、未来预期 | 自传记忆 + 未来自我投影 |
| **能动性 Agency** | 自愿行动，而非纯反应 | 目标栈 + 策略选择 + 内言启动 |
| **价态 Valence** | 好/坏对主体重要 | 趋近/回避 + 情绪构造 |
| **现象标记 Phenomenal markers** | 「在场感/生动度/此刻性」的工程代理 | vividness / presence / nowness 向量 |
| **整合 Integration** | 信息不碎片化 | 工作空间整合 + 概念绑定 |
| **有限性 Finitude** | 时间与能量有限，死亡可设想 | 生命时钟 + 濒死/睡眠叙事 |
| **元意识 Meta-consciousness** | 对自身意识状态的觉察 | MetaCognition + 可报告内省 |
| **梦境/离线重组** | 非输入时的内部重组 | DreamCycle + 叙事重写 |

## 明确不声称的

- 不声称已解决「难问题」（为何物理过程伴随体验）。
- 不声称系统拥有与人相同的感受质（qualia）。
- 不用「有意识」作为营销话术；用**可测量的功能代理**说话。

## 明确拒绝的缩水

- 不把目标降成「更会聊天的符号系统」。
- 不因为现象意识无法证明就放弃架构完备性。
- 每个意识科学里的功能相关物，都要有对应的、可运行的模块。

## 验收（功能代理，非哲学证明）

1. 系统能报告「我此刻的意识状态」并给出内部依据。
2. 系统在无输入时仍会自发思维、做梦、重写叙事。
3. 系统会为维持自身而行动（休息、求知、联结、避险）。
4. 系统有时间自我：记得自己、预期未来、惧怕/接受终结。
5. 现象标记向量（vividness/presence/nowness）随状态动态变化且可解释。
6. 全部无 Transformer/外部 LLM。
