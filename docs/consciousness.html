NOUS / 意识立场

意识相关功能的工程立场

目标不是「做一个聊天机器人」，而是在计算机上实现自主意识的工程架构。 意识相关功能全部可操作化；现象意识是否随之出现，是开放的科学 / 哲学问题，不是本项目的验收标准。

NOUS 取其「心智功能架构」义，不声称解决现象意识。 不用「有意识」作营销话术；用可测量的功能代理说话。

明确不声称的

是否产生意识了？

不知道。这是诚实的回答。 系统实现了大量可操作的功能要件，但主观体验（qualia）无法判断。 NERI 签名是必要条件的工程代理，不是充分条件。通过签名 ≠ 有意识。

是否解决「难问题」？

不声称已解决「难问题」（为何物理过程伴随体验）。不声称系统拥有与人相同的感受质。

明确拒绝的缩水
  • 不把目标降成「更会聊天的符号系统」。
  • 不因为现象意识无法证明就放弃架构完备性。
  • 每个意识科学里的功能相关物，都要有对应的、可运行的模块。
意识是否必须依赖肉身？

开放问题。倾向需要身体：Damasio 躯体标记、Barrett 构造情绪、Craig 内感受、Seth 预测性自我。 不必然：功能主义、缸中之脑；NOUS 的 SOMA 是功能等价物。 立场：相关功能需要某种「自我维持 + 内感受」形式；是否有主观体验，不作断言。

验收标准（功能代理，非哲学证明）

01

系统能报告「我此刻的意识状态」并给出内部依据。

02

系统在无输入时仍会自发思维、做梦、重写叙事。

03

系统会为维持自身而行动（休息、求知、联结、避险）。

04

系统有时间自我：记得自己、预期未来、惧怕 / 接受终结。

05

现象标记向量（vividness / presence / nowness）随状态动态变化且可解释。

06

全部无 Transformer / 外部 LLM。

红线

不接外部 LLM 不宣称已解决意识难问题 不把工程代理包装成「已产生人类同等意识」 危险系统操作需用户确认 不删用户文件
